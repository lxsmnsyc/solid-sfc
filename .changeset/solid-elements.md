Remove the `solid:` elements that control flow blocks replace: `<solid:for>`, `<solid:show>`, `<solid:switch>`, `<solid:match>`, `<solid:repeat>`, `<solid:errored>`, `<solid:loading>`, `<solid:reveal>` and `<solid:portal>`. Using one is a compile error that names the block to use instead.

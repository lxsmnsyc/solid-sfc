Remove the `solid:` elements that control flow blocks and dynamic tags replace: `<solid:for>`, `<solid:show>`, `<solid:switch>`, `<solid:match>`, `<solid:repeat>`, `<solid:errored>`, `<solid:loading>`, `<solid:reveal>`, `<solid:portal>`, `<solid:hydration>`, `<solid:no-hydration>` and `<solid:dynamic>`. Using one is a compile error that names what to use instead.
